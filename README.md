# Police Brutality 1.0

Police Brutality is a standalone pursuit mod for the supported Windows Steam build of Mafia II Definitive Edition. It adds staggered car and foot reinforcements, three-minute searches, and improved police pursuit driving.

## Install

1. Download `Police-Brutality-1.0-Installer.zip` from the [latest release](https://github.com/VonCauli/police-brutality/releases/latest) and extract the entire ZIP.
2. Quit Mafia II Definitive Edition. In Steam, open **Manage → Browse local files** for the game.
3. Run `PoliceBrutality.exe`, choose `install`, and enter the game folder that contains `pc`. Launch the game normally after installation.

For **Friends for Life 1.1**, install it first. The installer detects its original archive and applies the compatibility patch automatically.

The installer checks the game and archive versions before writing. If it reports an existing `dinput8.dll` or an unrecognized archive, use a supported clean installation or resolve the conflict first.

## Uninstall

Quit the game, run `PoliceBrutality.exe`, choose `uninstall`, and enter the same game folder. The installer uses the backups in `.police-brutality` to restore the archives and removes its own loader. Keep that folder until uninstall is complete.

## Verification

Install and uninstall were verified against clean base-game and Friends for Life 1.1 file copies. Live gameplay of this standalone package is pending.
